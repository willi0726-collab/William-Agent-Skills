# Amazon Listing

## Overview

Use this skill to create or improve Amazon listing content that is clear, compliant, keyword-aware, and conversion-focused. Separate confirmed product facts from suggested positioning.

## Workflow

1. Confirm marketplace, language, product category, target customer, variation structure, and available product facts.
2. Collect keyword inputs from the user, Amazon Ads/search term data, competitor research, or current listing text. If current marketplace data is needed, browse and cite sources.
3. Draft or audit listing modules: title, bullets, description, A+ content, backend search terms, image stack, and variation copy.
4. Check every claim against provided evidence. Flag unsupported claims instead of inventing certifications, performance numbers, or medical benefits.
5. Return copy in a reviewable table with rationale, keyword coverage, and compliance notes.

## Listing Standards

- Put the strongest shopper-facing value proposition early.
- Keep titles readable; do not keyword-stuff.
- Use bullets for concrete benefits, proof points, compatibility, dimensions, materials, and use cases.
- Avoid competitor trademarks unless the user provides a legitimate compatibility use case.
- For backend search terms, remove duplicates, punctuation clutter, brand names, and claims that should not be indexed.

## Image and A+ Guidance

For image prompts or creative briefs, specify scene, product angle, key callouts, model/use context, required text, and negative constraints. Do not promise exact rendered text unless the target image tool reliably supports it.

## Guardrails

Do not create deceptive claims, fake reviews, prohibited health claims, or fake origin/certification statements. When Amazon policy risk is possible, label it for review instead of presenting it as safe.
